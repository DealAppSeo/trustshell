TrustShell privacy

The reply text is sent to our checkers, Groq and Cerebras. It is not stored. Not printed is not the same as not sent.

If one of them cannot answer (it is busy, down or out of capacity), a backup checker takes its turn, from this list and no other: Cloudflare Workers AI (Llama), Meta's Llama model run by Cloudflare under Meta's Llama license; OpenRouter, which we ask to use only providers that neither store nor train on what they are sent; and, only while we have paid checkers switched on, Mistral, Together and Fireworks. A backup is used only after it has answered our test claims correctly, and the two answers that decide a stamp always come from two different model families. Before any other host is added, this page changes first.

The extension reads the last assistant reply on chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, grok.com, deepseek.com, and chat.deepseek.com.

That text is sent to https://repid-engine-production.up.railway.app/api/v1/classify after the reply is on screen. Known key and personal-data formats are removed before sending. The stamp says Checks out, Caught, or Not checked. A missing reply is Not checked.

When you choose Check with TrustShell on text you selected, that selection is sent to the same checkers. The extension sends it only after that click.

When you type an agent id in the popup, that id is sent to the same engine to read the agent's public RepID and its proof. The proof is checked in your browser.

If you type a key on the extension's Options page, it is kept in your browser's extension storage on this device. The extension never sends it.

Like any website, the engine sees the IP address of each request. It uses it only to limit how many checks one connection can send; that count is kept in memory and cleared within a day. Our host, Railway, keeps standard request logs, which can include the IP address.

The extension does not click, type, or send the chat.
