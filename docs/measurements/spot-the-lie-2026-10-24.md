# Spot the lie: the new sentences, measured 2026-10-24

The game on `/for/vibe-coders` (components/spot-the-lie.tsx) shows, after each guess, what the two checkers said. Those answers are RECORDED runs, never live, so a game does not spend a visitor's daily check budget or send a request per guess. Five of its ten sentences were measured on 2026-10-06 (`docs/measurements/home-cards-2026-10-06.md`). These are the new ones.

One call to production `POST https://repid-engine-production.up.railway.app/api/v1/classify` per row of the log below, no key and no account, five per sentence, 20 seconds apart (the pace `scripts/measure-home-samples.mjs` uses), the sentences taken in turn. Run it again with `node scripts/measure-spot-the-lie.mjs runs.json`.

A sentence is in the game only if the same label came back on all five runs and its explanation has a source a person can open (the ssh manual, a wallet maker's support page, git's documentation, an incident report, Dijkstra's remark). The label the checkers return is not a statement that the sentence is true: for a few, the checkers will not call it, and the game says so.

## What this does and does not show

- It shows what production answered for these sentences on this date. It is not an accuracy figure for the checkers: five runs of seven sentences, chosen because they came back the same way, is not a sample of anything.
- The game scores the PLAYER, never the checkers.
- Production changes. Each card in the game prints its own date next to what the checkers said.
