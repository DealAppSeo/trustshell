# Join kit

Five commands. No wallet. No new package version.

## 1. Install

```bash
npm i -g @hyperdag/trustshell@1.4.0
```

## 2. Verify

```bash
trustshell verify "<claim>"
```

## 3. Status

```bash
trustshell status
```

## 4. RepID

```bash
trustshell repid <id>
```

## 5. Proof

```bash
trustshell proof <id> --verify
```

The same five lines are the box on the landing page. Staking is not live. There is no mesh in this kit.
