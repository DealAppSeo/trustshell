# Security

Report vulnerabilities **privately** via [GitHub Security Advisories](https://github.com/DealAppSeo/trustshell/security/advisories/new) on this repository. One contact. Do not file a public issue for an undisclosed vulnerability.

This package is a thin client against the hosted HyperDAG engine. It does not run trust computation on your machine. Testnet: Base Sepolia, not mainnet.
